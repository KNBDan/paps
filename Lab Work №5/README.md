# Лабораторная работа №5
## Тема: 
Реализация архитектуры на основе сервисов (микросервисной архитектуры)
## Цель работы: 
Получить опыт работы организации взаимодействия сервисов с использованием контейнеров Docker

## Задание 1. Создание контейнеров
Реализована контейнерная архитектура из трех взаимодействующих сервисов: user-backend, qr-service и ub-postgres. 

Клиентская часть представляет из себя Telegram, поэтому user-backend включает в себя часть, которая обращается к Telegram и часть с обработкой пользовательской информации.
Qr-service включает в себя генерацию и обработку qr кодов для других сервисов программы.
Ub-postgres отвечает за базу данных, которая хранит всю информацию о пользователях, активностях, визитах, компаниях и прочее.

Контейнеры запустились и стабильно работали, принимали и обрабатывали запросы. Ниже скриншот из Docker Desktop.

## Задание 2. Непрерывная интеграция

Настроена непрерывная интеграция через GitHub Actions (backend-ci.yml).
При push в ветку автоматически запускаются:
1. Сборка проекта
2. Gradlew check проверка
3. Интеграционные API тесты Postman
